# ART-6 — stations

`decorateStation` / `PlotDressing`. `AssetLibrary.station(kind)` wins when a model exists. Neon only for **state**, never decoration.

**Charger** (0,-1): cyan rings `#3CDCFF` that pulse only while the drone is on that cell; copper coil `#C27744` 1–2 parts; pylon light.

**Factory** (1,-1): dark hull, hopper, chimney; biofluid Neon slit `#4DFFB0` that flickers only while the drone is on the factory cell.

Don’t replace server station parts (attributes live there). Client dressing only.

**Verify:** from Control Mode you can tell charger vs factory at a glance; idle stations are dark, active ones glow.
